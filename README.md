# Большой обход

Образовательная игра от первого лица о бережном отношении к природе национального парка «Ленские столбы».

## Запуск
1. Установить Godot 4.7.2.
2. Импортировать `game/project.godot`.
3. Дождаться импорта ресурсов и нажать F6/F5 для запуска проекта (F5 — главное меню).

Целевая платформа: Windows x64. Рендерер: Compatibility. Интернет для игрового процесса не требуется.

## Игровой цикл
Исследование маршрута, сбор мусора, загрузка тележки, возвращение на базу и сдача. За доставленный мусор начисляется опыт; на базе доступны улучшения выносливости, тележки и безопасности. Есть карта, инвентарь, журнал, настройки и статистика обхода.

## Структура
- `game/` — проект Godot, сцены, GDScript, шейдеры и ресурсы.
- `source_art/` — редактируемые Blender-исходники моделей и логотипа.
- Тестовые сценарии находятся в `game/scripts/`; запуск: `godot --path game --script res://scripts/имя_теста.gd`.

## Статус
Рабочий прототип, не финальный релиз. Подключены фотографии и фотодневник, 21 подтверждённое название охраняемых растений, песочно-золотистый интерфейс, детальный персонаж с полной тенью и отдельные боковые хваты трёх предметов. Модели и иллюстрации растений стилизованы и не являются ботаническим определителем. Ландшафт и карта условны, не являются точной географической реконструкцией или туристическим навигатором. Хваты остаются стилизованными; геометрическая проверка отдельных контактов не доказывает анатомическую точность. Сквозной автоматический тест использует подготовленные позиции, не заменяет полное ручное прохождение. Самостоятельный Windows-экспорт отсутствует.
